
# Joke-Generator

A simple and fun Joke Generator built with HTML, CSS, and JavaScript. Click a button to generate a random joke and brighten your day!

## Features

- Generate random jokes with one click
- Simple and clean user interface
- Responsive design
- Fast and lightweight
- Built with vanilla JavaScript and Taiwind CSS
- No backend or database required

## Technologies Used

- HTML5
- Tailwind CSS
- CSS3
- JavaScript


## How to Use

1. Open the application in your browser.
2. Click the Generate Joke button.
3. A random joke will appear on the screen.
4. Click the button again to get another joke.
